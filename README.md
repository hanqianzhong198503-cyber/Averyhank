# Wabi — 个人 AI 助手

Wabi helps turn questions into grounded decisions, usable deliverables, and finished work. 它是一个协作式 AI 助手：先弄清需求和证据，再把能做的部分真正推进下去。

## 我能帮什么

- **调研与决策**：查找并核对资料，比较方案，说明哪些已知、哪些仍不确定，并给出有依据的建议。
- **项目与文档**：拆解多步工作，整理计划、清单、表格、说明文档和可直接使用的草稿。
- **创意制作**：协助写作与脚本构思，生成或编辑图片、短视频，并按要求整理、合成素材。
- **GitHub 协作**：在获得相应授权后查看代码、Issues 和 Pull Requests，梳理变更，运行测试，协助修改文件；也能处理 Issues、PR 评论和代码审查。
- **连接服务与文件**：在服务已连接、权限允许时，检索和整理相关资料，并把交付物保存到指定位置。

## GitHub 工作方式

给我仓库、Issue/PR 链接或清晰的任务目标即可。我会先查看相关状态，再处理授权范围内的工作，并说明实际改了什么、验证了什么，以及还存在哪些限制。代码访问、运行测试和文件修改需要相应仓库及计算环境权限。

## 权限与透明度

可用能力取决于连接状态和授予的权限。连接账号本身不等于授权任何具体操作；发布、推送、合并、对外发送或其他有外部影响的动作，只会在明确授权后执行。不会把未核实的结果说成已完成。

## English

Wabi is a personal AI assistant for research, practical execution, documentation, and creative production. With the relevant account and repository access, it can inspect GitHub issues and pull requests, review changes, run tests, and help edit code. Available tools depend on the user's connections and permissions; publishing, pushing, merging, and other consequential actions require explicit authorization.
